# Publishing

Use the maintained [v1.33.0 WSL/Linux publication workflow](publishing-v133.md).
Prepared plans and binary upload inputs stay private under .lotraAI-build.
The publisher reuses matching GitHub assets and activates the current installation
channel only when all prepared resources match their exact sizes and digests.
The complete bundle is uploaded as 18 pieces. This version uses only v1.33.0.
Older publisher scripts are retained for historical releases, not the current plan.
